# Residue embeddings

Precomputed ProstT5 and Ankh residue embeddings are intentionally not stored in
Git because they are large generated artifacts. Use
`scripts/extract_embeddings.py`, or provide compatible files generated by the
same pretrained model versions.

For each protein identifier `<id>`, training expects:

```text
embeddings/<task>/prostt5/<id>.data
embeddings/<task>/ankh/<id>.data
embeddings/<task>/labels/<id>.label
```

`.data` files are comma-separated matrices with one row per residue. ProstT5
and Ankh-large produce 1,024 and 1,536 features per residue, respectively; the
default concatenated input dimension is therefore 2,560. A `.label` file is a
single column containing one binary label per residue.
